# RemoteLipSync HTTP 集成实施清单

范围：两个项目的口型客户端、服务端、测试及说明；保留已有其他云端适配器、前端、数据库和任务流水线。

- [x] 可选提交体 `timeline=strict|audio`；省略仍 strict，非法值 422，同上传换模式提交 409。
- [x] 每个任务保存并返回模式和预期输出时长；排队时预期时长可为 null。
- [x] 模式随 IPC 请求传递，常驻模型在 strict/audio 交替任务间复用，不修改全局模式。
- [x] audio 使用完整音频、正放/倒放循环或较短输出；strict 保留原视频时间线。
- [x] 有理数帧率计算帧数，避免边界少一帧；无法满足 150ms 取整容差的低帧率明确失败。
- [x] HTTP health 广告支持模式；不支持 audio 的引擎拒绝相应任务。
- [x] 客户端显式模式、相应输入/输出时长校验，以及服务端模式/预期时长确认。
- [x] 模式进入检查点身份；切换模式新建任务，旧无模式检查点仅在 strict 下迁移。
- [x] 独立就绪等待、持续 503 恢复、总任务预算约束、鉴权/输入错误快速失败。
- [x] PATCH 恢复后先重新读取偏移，下载恢复使用 Range，避免重复数据和错误追加。
- [x] 已接收任务继续查询原 ID，失败任务不自动重提，服务器重启 404 后重建会话。
- [x] 默认时间预算及长片/排队示例，明确输入预检/哈希不计入网络任务预算。
- [x] 非硬链接文件系统使用独占原子重命名；权限/磁盘错误不降级；失败保留 part/checkpoint。
- [x] 原调用、无提交体、模式切换、长短音频、常驻模型复用、失败与重启回归。
- [x] 54 秒模拟恢复、超时上限、无效健康 JSON、鉴权与模式/时长不匹配回归。
- [x] 非覆盖发布、发布竞争、磁盘满/权限错误、Windows 重命名分支回归。
- [x] README/API/base/AGENTS 约定同步，提供 `python -m pipeline.lip_sync.check_remote` 验证入口。
- [x] 完整回归 95 项及独立 CLI/TCP 2 项通过；检查 OpenAPI 可选提交体及时间线枚举。
- [ ] 使用实际局域网 GPU 服务完成最新 HTTP strict/audio 验收（待服务地址和可读取的人脸素材）。
- [ ] 人工播放输出检查口型、脸部融合和音画同步。
- [ ] Windows GPU/NTFS 及无硬链接文件系统的原生实机验收。

本地 TCP 用例运行真实服务、真实客户端和 FFmpeg；神经网络由测试引擎替代，不代表 GPU 质量验收。
历史服务器的两次 MuseTalk 直接推理已成功，不等于本次新增 HTTP 模式协议已在该服务器验收。
